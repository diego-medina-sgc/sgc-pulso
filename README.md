# sgc-pulso

Procesamiento programado de una biblioteca de fotos escolar: deteccion de
caras, agrupamiento y sugerencias. Corre cada hora en GitHub Actions.

Este repositorio es una copia generada automaticamente y **no contiene datos**:
ni fotos, ni nombres, ni claves. Los nombres de personas que aparecian como
ejemplos en los comentarios fueron reemplazados por "Persona A", "Persona B"...
El estado entre corridas (huellas de caras) se guarda cifrado con AES-256-GCM
y la clave no esta en el repositorio.

No se aceptan pull requests.
